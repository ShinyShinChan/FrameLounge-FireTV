# Frame Lounge VHS v1.5.0

- Catalog and search contain only titles in a **published FrameXTV link feed**.
- A FrameXTV listing link is presumed playable; absolutely no stream checks, iframe probing, or availability verification.
- Daily GitHub workflow refreshes `framextv-catalog.json` from FrameXTV published Movies and TV pages.
- TMDB enriches only FrameXTV-listed titles; it no longer introduces unlisted titles.
- Preserves VHS branding, angled VHS cases, local Likes/Dislikes/Watch Later, and the fixed Android SDK workflow.
- Version code 6 / version 1.5.0.
